# AI Attendance Assistant

**Idea in one sentence:** A Telegram bot that tracks a student's college attendance, warns them before it falls below 75%, and answers "Can I skip this class?"

Built for **Homingo Hack Days 2026** (Automation track, solo).

## What it will do
- Show attendance % for each subject
- Send an alert when a subject drops below 75%
- Answer "Can I skip this class?" with how many classes are safe to miss
- Read an attendance sheet photo with AI

## AI tools used
- ChatGPT: planning and code help
- Google Antigravity: coding agent for building the project
- Google Gemini (free API): reading attendance sheet photos and chat replies

All AI-written code is reviewed and tested by me.
